# Initial GLOBAL free-first static hosting catalog

**Evidence checked:** 2026-10-24 UTC. **Scope:** research-only, static/client-side web apps; 38 candidates with current first-party source checks. Country-specific entries have individual eligibility or implementation restrictions and are not uniformly good fits. The separate [paid/restricted/unverified local lead register](./providers-local-leads.md) is not part of this strict candidate count. This is a broad seed, not an exhaustive survey of countries or hosts. A separate full UN-state/observer coverage universe and logged search statuses is in [`country-coverage-ledger.json`](./country-coverage-ledger.json) and [`country-coverage-initial.md`](./country-coverage-initial.md). No accounts were created, no signup/deploy/payment/API calls were made, no credentials were requested or stored, and no provider was contacted.

## Useful findings first

- **Best static-first shortlist to investigate further:** Cloudflare Pages (free, unlimited static asset requests; CORS/CSP headers and SPA support documented), Firebase Hosting Spark (strong static/PWA support and many official document translations, but strict 10 GB-class limits and automatic site disabling over quota), and Azure Static Web Apps Free (globally distributed static content, 100 GB/month, clear headers/routes; “for personal projects” positioning). None is a permanence, availability-everywhere, or transaction/crypto permission guarantee.
- **Low-friction automation:** Cloudflare Pages, Netlify, Surge and Neocities offer CLI or API paths; Netlify has a ZIP/manual flow but its new Free plan is credit-limited. Git-based CI platforms are more portable but have provider-specific auth/CI requirements.
- **Material MirrorKit exclusions/cautions:** GitHub Pages explicitly disallows free hosting for sites primarily facilitating commercial transactions or commercial SaaS, and warns against sensitive password/card transactions. Vercel Hobby is noncommercial only. Codeberg is for free/libre software and personal homepages, not a generic commercial host. Surge terms restrict commercial exploitation of the platform and ban publishing identical/highly similar content to multiple subdomains. Neocities’ terms specifically constrain using its API to create sites for other people from a separate service. Render’s AUP prohibits crypto mining and other unauthorized commercial purposes. Deno Deploy expressly bans crypto mining (not the same claim as banning every token UI). These are not interchangeable; check intended use with the actual current terms.
- **Regional and language-localized evidence remains narrow:** Japan (XREA plus XServer Static, the latter Japan-resident/entity and Japan-network restricted), India (Voroa plus WebHostingKashmir, a 50 MB manual host with 10 GB fair-use and unverified asset-integrity claim), Taiwan (CosmoPage), Thailand (FreeHost.in.th), Viet Nam (CloudFly student-only), Malaysia-facing LamanRasmi (UK fulfillment), Pakistan charity-only, Bangladesh (restricted/banner-required), Nepal (operator/AUP incomplete), Iran (Persian Mizban), Uzbekistan, Nigeria, Russia and Brazil (SitePerto file-mirror policy warning), plus UK Static Host (be braver Ltd, Git deploy, quota/security details unknown), Czech Endora Free (noncommercial only, mandatory injected brand bar), and TUKE Slovakia (students/employees only). HTMLBox Community remains an anonymous 1 MiB upload with attribution/possible footer ads and unknown operator. Other leads (including Iraq URUK HUB) are unverified. Operator country, resident eligibility, data-center selection, service availability and docs language are separate facts; see the ledger.
- **Do not infer free forever from a $0 page:** free plans can change, pause, be suspended, require account verification, or impose a paid option. AWS Amplify is listed only as a time-limited/free-credit fallback, not as free-forever hosting.

## Critical-use safety gate (separate from general static hosting)

A browser app that draws original art/docs can be analyzed separately from a wallet, purchase, payment, signing, transfer, or P2P interface. Provider terms and actual app behavior must be matched; calling a financial app “artwork” does not erase the function. **No host here is vetted or approved for GhostPay/P2P/key-handling/payment UI.** Free-tier ad injection, analytics/CDP scripts, or unknown served-asset integrity is a default blocker for key-critical use until explicit provider permission, script integrity/no-tracking, CSP/CORS, domain/account security, privacy/data handling, payment/financial terms, recovery/rollback, and safe deployment authentication are all verified. “Not documented” is **unknown, not green**. Provider statements and legal registrations do not constitute independent uptime/security/financial-stability audits. See per-provider `hosted_asset_modification` and `mirror_suitability` fields.

## Interpretation rules

- `free recurring` means an official source describes a current $0/free plan; it is **not** a provider commitment that it will exist forever. `credit/trial` means not durable free hosting.
- `operator country` is the legal company’s published country/contracting entity, not the static-site’s origin server or CDN geography. Tencent’s contracting entity varies by the registrant’s location.
- `global CDN` describes a product marketing/technical statement; it does **not** prove that sign-up, domains, pages, or visitors work in every country. No provider’s static content region is called “selectable” unless that control is documented.
- CORS for static responses is different from CORS for provider account/deploy APIs. No credential-bearing deploy token belongs in a public browser app. XREA lists FTPS and SSH, but its static-file API workflow is undocumented; Voroa documents repository-based deploy; other transfer protocols must be checked provider by provider.
- The browser-executable app’s own payment/token behavior was not reviewed as code. Provider terms that ban mining/proxying or limit commercial activity are flagged without extending them into unsupported broader claims. **Suitability is separated by use:** general art/docs hosting is not approval for GhostPay/P2P or payment/key-handling UI. No provider in this seed is vetted or approved for such a critical payment/key use. Any confirmed ads/analytics/CDP/asset rewriting or unknown response integrity is unsuitable by default until explicitly resolved. Provider self-claims are not independent security/uptime verification.
- Prices are in USD when explicitly stated, and tied to the official page/date checked; no live purchase prices are quoted. For Neocities/Surge paid fallback, recheck current official pricing before decision.

## Provider fact sheets

### 1. Cloudflare Pages — strongest broad static-first seed

- **Free model/operator:** recurring free plan; Cloudflare, Inc. (US). Static requests are explicitly free and unlimited, separate from Pages Functions/Workers quota. Current documented limits: 500 builds/month, 1 concurrent build, 100 Pages projects/account, 20,000 files/site, 25 MiB/file, 100 custom domains/project. No static bandwidth cap was identified in the checked Pages limits/pricing docs.
- **Regional distinction:** globally distributed delivery is documented. Ordinary Pages static assets do not offer a normal per-site serving-region picker. Cloudflare Regional Services is separate/configured for eligible custom domains. Country-level service availability was not audited.
- **App support:** custom domains/TLS, `_headers` for CSP/CORS, `_redirects`, SPA fallback and rollback are documented. Static asset responses default to `Access-Control-Allow-Origin: *`; this is public-resource CORS, not credentials-enabled CORS. GitHub/GitLab integration, Dashboard ZIP upload (1,000-file limit), Wrangler CLI directory upload, and REST APIs. Dashboard drag-and-drop is the least-code manual route; token/API automation needs account authorization. Do not embed a token in the app.
- **Terms/risks:** no explicit free-page commercial prohibition found in Pages docs, but check service-specific terms/AUP against the future use. Free service is not a takedown/censorship-proof guarantee.
- **Primary evidence:** [Pages limits](https://developers.cloudflare.com/pages/platform/limits/), [static request pricing](https://developers.cloudflare.com/pages/functions/pricing/), [direct upload](https://developers.cloudflare.com/pages/get-started/direct-upload/), [headers/CORS](https://developers.cloudflare.com/pages/configuration/headers/), [SPA, defaults and asset serving](https://developers.cloudflare.com/pages/configuration/serving-pages/), [custom domains](https://developers.cloudflare.com/pages/configuration/custom-domains/), [Regional Services](https://developers.cloudflare.com/data-localization/how-to/pages/), [operator](https://www.cloudflare.com/our-story/).

### 2. Firebase Hosting Spark — static/PWA strong, hard quota

- **Free model/operator:** no-cost Spark has no payment method requirement listed by Firebase; Google LLC (US). Hosting storage is 10 GB. As checked 2026-10-24, Firebase Pricing shows 360 MB/day, while the detailed Hosting quota guide says 10 GB/month and disables Spark sites after a grace period at the monthly cap. They are both current first-party sources, but do not explain whether the daily figure is a separate guardrail or a daily expression of monthly quota; 360 MB/day is not exactly 10 GB for a 30-day month. Conservatively assume **both thresholds apply (whichever comes first)** until Firebase clarifies. No test was run. Blaze overages can be billed; do not link billing without authorization. Storage and transfer are project-level. Spark blocks new deployments after storage cap and disables sites after a short grace period when transfer quota is exceeded; Blaze enables paid overage and requires billing.
- **Regional distinction:** content is served through a global CDN; a Hosting region picker is not documented. Country-specific access was not audited.
- **Quota reconciliation note (official pages remain ambiguous):** [Firebase Pricing](https://firebase.google.com/pricing) says 360 MB/day; [the detailed usage/quota guide](https://firebase.google.com/docs/hosting/usage-quotas-pricing) says 10 GB/month and describes Spark disabling at that monthly limit. Both were checked 2026-10-24. The pages do not clarify if the daily value is an independent cap or rounded daily equivalent; 360 MB/day × 30 days is 10.8 GB decimal. Safest assumption is whichever of 360 MB/day or 10 GB/month arrives first; do not upgrade to Blaze unless billing authorized.
- **App support:** optimized for SPAs/PWAs, custom domains/zero-config TLS, redirects/rewrites/headers, previews, CLI, GitHub integration and one-click rollback. REST API deployment requires OAuth/service account and is **not** suitable for placing an admin credential in the browser. Official translations verified include Japanese, Brazilian Portuguese, Spanish, French, German, Chinese, Indonesian, Italian, Polish, Vietnamese, Turkish, Russian, Hebrew, Arabic, Persian, Hindi, Bengali, Thai and Korean (coverage may vary by article).
- **Terms/risks:** not a payment/crypto approval. Linking a Cloud Billing account can upgrade Spark to Blaze; do not do so without authorization.
- **Primary evidence:** [Firebase pricing](https://firebase.google.com/pricing), [Hosting quota and hard-stop behavior](https://firebase.google.com/docs/hosting/usage-quotas-pricing), [product overview and global CDN/TLS/CLI/rollback](https://firebase.google.com/docs/hosting/), [Hosting configuration/headers/rewrites](https://firebase.google.com/docs/hosting/full-config), [REST deploy API](https://firebase.google.com/docs/hosting/api-deploy), [Japanese docs](https://firebase.google.com/docs/hosting/?hl=ja), [Portuguese quota page](https://firebase.google.com/docs/hosting/usage-quotas-pricing?hl=pt).

## Candidate disposition for a client-side-only MirrorKit deployment engine

This is a hosting catalog, **not** an engine approval. Current strongest research leads for general static art/docs: Cloudflare Pages, Netlify manual/ZIP, GitHub/GitLab CI (only where terms allow), Firebase local CLI (not browser API), Surge CLI, Voroa GitHub deploy, and selected FTP/manual local hosts. This first pass used official product docs, plans, quotas, legal terms, language-localized official docs, and targeted web search across providers. It is not exhaustive per country. Next research pass should use distinct search engines and local-language terms/directories for under-covered markets; test only official documentation, log actual query/language/source, inspect country-by-country legal operator/service availability, and include blockchain/content-addressed hosts only after verifying legitimate operators, current terms, browser-fetch/CORS compatibility, size limits, content persistence/exit, and regional reach.
