# Replikrazy

This repository is the public research/specification workspace for browser-first static-site mirroring. The work began under the historical working name **MirrorKit**; that name in older notes records provenance, not a separate active repository.

The initial content is research and specifications only—no application implementation, provider qualification, runtime test, or deployment is claimed. The separate `docs/research-intake-20261025` branch holds the initial source-cited research package for review and is not merged or released.
